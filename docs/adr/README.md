## 運用規則

- 一つの ADR には一つの長期的な判断を記録する
- 採用、不採用、置換済みの状態を明示する
- 後続 ADR が一部を置き換える場合は、双方から参照する
- 実装手順、調査ログ、実機測定値は `worklog/` に分離する
- 現行コードと状態が食い違った場合は ADR を更新するか、新しい ADR を追加する
