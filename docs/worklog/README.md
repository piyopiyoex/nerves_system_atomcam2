## 新しい記録の書き方

- ファイル名は `YYYYMMDD-内容.md` とする
- 見出しは `# YYYY-MM-DD 内容` とする
- 現行仕様を断定せず、必要に応じて上位文書へ案内する
- 長期的な設計判断になった内容は `docs/adr/` に別途記録する

```text
## 文書情報

- 日付: YYYY-MM-DD
- 種別: 作業記録 / 技術調査 / 設計検討 / 検証記録 / 実装記録
- 状態: 完了 / 調査完了 / 検討完了 / 継続課題 / 記録不完全
- 位置づけ: 現在どの資料を優先するか
- 現行資料: [構成](../構成.md) / [運用](../運用.md)
```
