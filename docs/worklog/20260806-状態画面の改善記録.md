## 実装内容

### 1. 映像タブ

| 変更 | 内容 |
| --- | --- |
| アプリ/camd バージョン表示 | `App: <nerves_fw_version>  camd: <camd VERSION>` を RTSP URL の下に追加。camd 側は起動時に `/tmp/camd.version` を書き出し(`CAMD_VERSION`、`atomcam2-camera.mk` の `ATOMCAM2_CAMERA_VERSION` と同期させる運用)、`CameraNative.camd_version/0` で読む |
| 画像リフレッシュ間隔 | 1 秒 → **0.5 秒**。サーバ側レート制限も `@snapshot_min_interval_ms` を 1,500 → **500ms** に変更(VERSION 30 で独立バッファ化済みのため、この値はもう「H.264 チャンネルへの干渉を防ぐ」目的ではなく「無駄な再エンコードを避ける」だけの意味に変わった、とコメントを更新) |
| 表示サイズ | `width: 80%` → 一旦 `max-width: 100%` のみ(原寸)に変更したが、フル解像度化後は 80% 縮小表示に戻した(現状 `width: 80%; max-width: 100%`) |
| スナップ表示 ON/OFF トグル | **削除**。旧実装は「スナップ表示がRTSPに影響するか A/B テストするため」の切替だったが、VERSION 30 の独立バッファ化で前提が変わったため不要と判断し、ボタンと関連 JS(`toggleSnap`/`renderSnapToggle`/`snapEnabled`)を削除 |
| 夜間 ON/OFF/自動 | **復元**。[2026-08-04 の技術相談](20260804-ネイティブカメラ不具合の調査.md)で「夜間 ON で RTSP が止まる」不具合が報告されて以来 UI から外れていたが、原因(`SetISPRunningMode` をエンコードループ中に呼んでいたこと)は同日中に camd 側で修正済み(IR-cut + IR LED のみに変更)と確認できたため、映像タブに Ajax ボタンとして復元した |

### 2. 操作タブ(テスト発声・再起動)

`<form method="post">` によるページ遷移を廃止し、`fetch()` ベースの Ajax
に変更(`window.postOp`)。ボタン押下 → 確認ダイアログ → 実行中/OK/失敗を
`#ops-status` に表示、という流れになり、画面遷移が起きない。

- サーバ側(`router.ex`)は `redirect_home(...)` の HTML フラグメント
  ではなく `application/json` を返すよう変更(`/announce` `/reboot`)。
- Basic 認証(401 + `WWW-Authenticate`)はフォーム送信時と同様に
  `fetch()` でもブラウザのネイティブ認証ダイアログが機能する。

### 3. 動作確認タブ(ハードウェアテスト)

同じ Ajax 化を LED/スピーカー/IR-cut/マイクの全ボタンに適用
(`#hwtest-status` に結果表示)。

- `/test/blue` `/test/yellow` `/test/ir_led` `/test/speaker`
  `/test/ircut/on` `/test/ircut/off` — `redirect_home` → JSON 応答。
- マイク録音・再生(`/test/mic/record` `/test/mic/play`)は、従来は
  サーバがカウントダウン付きの**別ページ全体**(`countdown_page/2`、
  meta refresh でタブへ戻る)を返していたが、**秒数だけを JSON で返し、
  カウントダウンはクライアント JS(`window.postMic`)側で行う**方式に
  変更。ページ遷移が無くなった。
- 上記に伴い `router.ex` の `redirect_home/1` と `countdown_page/2` は
  呼び出し元が無くなったため削除(`/night/` だけは API 用途として残す
  想定だったが、これも映像タブに移設して Ajax 化したため実質フォーム
  経由の呼び出しは無くなっている)。

## 実施結果(追記): 「操作」タブの重複削除

上記「2. 操作タブ」実装後、実運用の中で「操作」タブの**テスト発声**
ボタンが「3. 動作確認タブ」の**スピーカー(発声)**ボタンと**完全に
同一の処理**(`System.cmd("/usr/bin/atomcam2-boot-announce", [])`)を
呼んでいることが判明した(`HardwareTest.speaker/0` と `router.ex` の
`/announce` ハンドラの実装が同じコマンド呼び出し)。

- **「操作」タブを削除**。テスト発声の重複ボタンも削除(動作確認タブ
  の「スピーカー(発声)」で代替可能)。
- 重複していなかった**「再起動」ボタンのみ動作確認タブへ移設**
  (`#hwtest-status` に結果表示、他のボタンと同じ Ajax パターン)。
- ナビゲーションは 映像 / 状態 / ログ / 動作確認 の 4 タブに整理。
- 192.168.1.77・192.168.31.31 の両機で、`href="#ops"` が無くなった
  こと・動作確認タブに再起動ボタンが表示されることを実機確認済み。
