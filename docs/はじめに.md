# はじめに

この文書では、ソースコードからファームウェアを作成し、MicroSD カードへ書き込み、
Nerves、SSH、状態画面、RTSP 映像を確認します。

## 必要なもの

- Atom Cam 2
- MicroSD カード
- Elixir、Mix、Nerves、fwup を利用できる開発環境
- 2.4 GHz Wi-Fi の SSID とパスフレーズ
- SSH 公開鍵
- RTSP を確認できる VLC などの再生ソフト

初回書き込みでは MicroSD カードの内容を消去します。書き込み先を誤ると、開発機の
別の記録媒体を消去する危険があります。

## 1. ファームウェアを作る

サンプルアプリへ移動し、対象機器と Wi-Fi を設定します。

```sh
cd examples/atomcam2_nerves_app

export MIX_TARGET=atomcam2
export MIX_ENV=prod
export NERVES_WIFI_SSID="your-ssid"
export NERVES_WIFI_PASSPHRASE="your-passphrase"
```

通常は `~/.ssh/*.pub` がファームウェアへ追加されます。使用する鍵を明示する場合は
次を設定します。

```sh
export ATOMCAM2_AUTHORIZED_KEYS="$HOME/.ssh/id_ed25519.pub"
```

依存関係を取得し、ファームウェアを作成します。

```sh
mix setup
mix firmware
```

## 2. MicroSD へ書き込む

```sh
mix firmware.burn
```

fwup が表示する書き込み先を確認し、対象の MicroSD カードを選択します。書き込み後、
Atom Cam 2 の電源を切った状態でカードを挿入し、電源を入れます。

同じファームウェアを再度書き込む場合は次を使用できます。

```sh
mix burn
```

## 3. Nerves と SSH を確認する

起動とネットワーク接続を待ってから確認します。

```sh
ping nerves.local
ssh nerves@nerves.local
```

SSH 接続すると、機器上の IEx が開きます。

```elixir
Atomcam2NervesApp.CameraNative.status()
Atomcam2NervesApp.Dashboard.enabled?()
```

ここまで成功すれば、Nerves、ネットワーク、SSH、ネイティブカメラの管理処理が
起動しています。

## 4. 状態画面を確認する

状態画面は既定で有効です。

```text
http://<機器のIP>/
```

次の取得口も利用できます。

```text
GET /healthz
GET /status.json
GET /snapshot.jpg
```

読み取りは認証なしです。再起動や動作確認などの書き込み操作は、管理用パスワードを
設定するまで拒否されます。

```elixir
Atomcam2NervesApp.Dashboard.set_password("十分に長い固有のパスワード")
```

パスワードは `/data/atomcam2-dashboard/password.conf` に平文で保存され、権限は
`0600` に設定されます。信頼できないネットワークへ接続する場合は、状態画面を
無効にするか、別の安全な管理経路を用意してください。

```elixir
Atomcam2NervesApp.Dashboard.enable(false)
```

## 5. RTSP 映像を確認する

ネイティブカメラは既定で起動し、RTSP サーバーも同じ管理処理から起動します。

```text
rtsp://<機器のIP>:8554/video0_unicast
```

VLC などで URL を直接開きます。状態は IEx から確認できます。

```elixir
Atomcam2NervesApp.CameraNative.status()
```

`phase: :running` で、`camd_pid` と `rtsp_pid` が設定されていれば、映像経路は
起動しています。

## 6. IP アドレスを安定させる

DHCP では再起動後に IP アドレスが変わることがあります。RTSP、状態画面、遠隔更新を
安定して利用するため、ルーター側で MAC アドレスに対する DHCP 予約を設定します。

MAC アドレスは IEx から確認できます。

```elixir
cmd("ip -o link show")
```

有線 `eth0` と無線 `wlan0` は別の MAC アドレスです。両方を使う場合は、それぞれを
登録します。

## 7. 遠隔更新を確認する

初回の完全書き込み後は、ホスト側から更新できます。

```sh
mix firmware
mix upload nerves.local
```

更新候補は現在使っていないスロットへ書き込まれます。再起動後のヘルスチェックに
成功すると確定し、失敗が続く場合は直前の確認済みスロットへ戻ります。

## うまく動かないとき

### `nerves.local` が見つからない

- 開発機と Atom Cam 2 が同じネットワークにいるか確認する
- 2.4 GHz Wi-Fi の SSID とパスフレーズを確認する
- 開発機で mDNS が利用できるか確認する
- ルーターの管理画面から DHCP の割り当てを確認する

IP アドレスが分かる場合は、名前の代わりに直接指定します。

```sh
ssh nerves@<機器のIP>
```

### 標準 Atom アプリだけが動く

標準 Atom アプリでは映像が見える一方、SSH に接続できない場合は、MicroSD から
Nerves が起動せず、内蔵側の純正ファームウェアで起動している可能性があります。

### MicroSD の構成を確認する

電源を切り、MicroSD を開発機へ接続します。

```sh
lsblk /dev/sdX
```

標準構成では FAT、アプリスロット A、アプリスロット B、`/data` の四領域が見えます。
詳細な復旧手順は [運用](運用.md#記録媒体を復旧する) を参照してください。
